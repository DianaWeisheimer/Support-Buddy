# Support Buddy

AI-powered support tool for getting next steps and better customer messages!.

## Features

- **Case context panel** — ID, category, priority and problem description
- **Investigation log** — track steps already investigated
- **Next steps suggestion** — GPT analyzes the full context and suggests what to do next
- **Message improver** — refine customer messages using case context as reference

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the app

```bash
streamlit run app.py
```

The app will open automatically at `http://localhost:8501`
